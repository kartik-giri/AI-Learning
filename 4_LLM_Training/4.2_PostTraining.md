# What is posttraining?
- The postraining is the process of taking the pretrained model and further training and adapting it to behave more like the useful assitent but not just like  the next token predicter.

- A pretrained model learns to continue text. But we want an AI assistant that can:
- Follow instructions.
- Answer questions.
- Explain concepts.
- Follow a requested format.
- Refuse certain unsafe requests.
- Admit when it doesn't know something.
- Interact conversationally.

- We need another training stage.


# Supervised fine tuning.
- The supervised fine tunning is the machine learning method which is used to train or adapt the pretained model to the specific task, format or bhaviour using the labeled input and output examples.

- How it works:
1. Labeled Pairs: You train a base model on curated examples containing a prompt or input and a target output.
2. Weight Updates: The model predicts tokens or outputs, compares them against the target labels, and adjusts its weights using a lower learning rate than pre-training.
3. Efficiency Options: Teams can update all model parameters (full fine-tuning) or use Parameter-Efficient Fine-Tuning (PEFT) methods like LoRA or QLoRA to lower compute and memory costs

- SFT teaches the model how to respond using curated examples of good input-output conversations.

During SFT:
1. The input is passed through the pretrained model.
2. The model predicts an output token by token.
3. Its predictions are compared against the expected output tokens.
4. A loss is calculated.
5. Backpropagation calculates gradients.
6. The optimizer updates the model's trainable weights.
This process repeats across many curated examples.

- The result is a model that becomes better at following instructions and producing the kinds of answers demonstrated in its training examples.

- Approach	What happens to weights?
- Full fine-tuning	Most or all model weights are updated
- LoRA	Original weights are usually frozen; small additional trainable matrices are updated
- QLoRA	Uses a quantized frozen base model and trains LoRA adapter weights


# Reinforcement learning through human feedback.
- The RLHF is the mchaine learning technique in which the model learn the human prefernce and generate the human freindly respones.


- How RLHF Works
1. Supervised Fine-Tuning (SFT): A pre-trained base model is fine-tuned on high-quality human-written demonstrations of prompts and ideal responses so it learns how to follow instructions and formats.

2. Reward Model Training: The model generates multiple outputs for a prompt, and human evaluators rank them from best to worst. A separate reward model trains on these rankings to predict a numerical quality score for any given output.

3. Policy Optimization: Using reinforcement learning algorithms such as Proximal Policy Optimization (PPO) (often paired with a penalty to keep outputs close to the original model), the main model updates its weights to earn higher scores from the reward model.

- RLHF uses human preferences to further optimize how an LLM responds.
