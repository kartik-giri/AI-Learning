# How does an LLM generate an entire response?
1. Client prompts the LLM.
2. LLM analyse the context, the exisitng tokens.
3. Than LLM predicts the next token.
4. LLM than slects and appends the perfect token to the sequence.

- Than LLM repeat the step 2 to 4 unitl whole generation is done.
- This process is called autoregressive generation.
- The autoregressive generation is the process of continuous predicting, selecting and appending the token unitl the whole response is complete.
- The new token is predicted on the basis of current tokens.

# How does an LLM become capable?
- At a high level, capability comes from four major factors:

1. Training data: More diverse and high-quality examples help the model learn patterns.
2. Compute: Powerful hardware allows large-scale training.
3. Model architecture and parameters: The design and capacity of the neural network affect what it can learn.
4. Training techniques: Better training methods improve how effectively the model learns and follows instructions.


1. What is an LLM?
- An LLM (Large Language Model) is a neural network trained on large amounts of data to learn patterns in language and other tokenized information.

2. What is next-token prediction?
- Next-token prediction is the process in which an LLM predicts the probability of the next token based on previously available tokens.

3. Autoregressive generation:
- The process of generating text by repeatedly predicting, selecting and appending the next token until the response is complete.
